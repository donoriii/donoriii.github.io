What this app does

This is a private desktop/command-line utility used by its account owner for Google Drive project backups. It reads account and file metadata to check access, downloads selected files, and creates or updates explicitly approved backup files in designated private folders. It is not a public signup service.

  • 프로젝트별 목적지와 파일 범위를 확인합니다.
  • 파일 조회·다운로드·업로드·내용 갱신은 승인된 작업에 한해 실행합니다.
  • 일반 작업 완료가 자동 업로드나 공유 설정 변경을 의미하지 않습니다.
  • 백업 후 파일 식별자·버전·해시 등 복구에 필요한 정보를 확인합니다.

Google Drive access

The current backup workflow requests the Google Drive permission https://www.googleapis.com/auth/drive. This broad permission can allow viewing, editing, creating and deleting Drive files. The utility uses it to work with existing registered folders/files and in-place updates; it does not provide automatic deletion or public-sharing operations.

OAuth consent runs in the account owner's browser. Authorization returns to a local loopback callback, not to this website. Credentials remain in restricted local storage. This website does not receive authorization codes or credentials.
